# 📐 从空画布到户型图

[← 功能介绍](../README.md) · [部署教程](DEPLOY.md)

## 1. 建立项目

点击“新建户型”，按需要填写小区、格局、朝向与目标面积。资料可通过顶部编辑入口再次调整。第一次使用可以先跟随“试用引导”，不必一次掌握全部工具。

## 2. 先结构，后细节

先用 `Q` 绘制墙体或 `W` 创建矩形房间。结合端点吸附与正交对齐完成闭合轮廓，再放门窗、标注房间。若已有底图，可导入参考图进行临摹与比例校准。

绘制时先保证相对比例合理，再利用尺寸与面积设置校准。建筑面积和室内可用面积概念不同，录入时请确认所用口径。

## 3. 门窗与家具

- `A` 单开门，`S` 双开门，`D` 推拉门，`F` 窗户，`Z` 垭口。
- `E` / `V` 返回选择，点击对象调整属性。
- 拖家具主体移动，拖边缘控制点缩放；旋转手柄可点击转 90°，也可拖动旋转。
- 方向键精细移动，`Ctrl + 方向键` 快速移动，`Shift + 方向键` 贴墙。
- 误操作可 `Ctrl + Z` 撤销，`Ctrl + Y` 重做。

## 4. 多楼层

通过画布楼层控件增加地上或地下楼层，或复制当前楼层到指定楼层。逐层检查房间名称、尺寸与家具，再进行整套导出。

## 5. 保存与输出

自动保存会写入本地快照，但当前版本启动仍载入示例，未接通自动恢复。请及时下载 JSON 和图纸留存。PNG / JPG 用于发图，SVG 用于矢量编辑，JSON 用于留存结构数据（当前界面没有通用 JSON 文件导入入口）。多层导出会包含独立楼层与总览图，浏览器可能要求允许多文件下载。

## API 配置

无需配置任何外部 API。当前仓库没有服务器账号、云数据库或多人实时协作接口；跨设备编辑尚未提供完整导入流程，JSON 可用于结构数据留存。
