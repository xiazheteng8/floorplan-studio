## 🚀 启动与访问

### 方式一：双击启动（推荐 Windows 用户）
直接双击运行根目录下的 `start.bat`，程序将自动启动本地服务并打开浏览器。

### 方式二：命令行启动
在项目根目录下运行：
```bash
python server.py
# 或使用内置模块：
python -m http.server 8080
```

### 访问地址（直接访问 IP:端口，无需加 /index.html）：
- **本机浏览器访问**：[http://localhost:8080](http://localhost:8080)
- **局域网手机/平板/其他电脑访问**：`http://<本机局域网IP>:8080` （例如 `http://192.168.10.99:8080`）

## ⌨️ 核心快捷键指南

### 1. 人体工学绘制快捷键
| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **Q** | 画直线墙体 | 支持智能端点吸附、正交对齐与相邻墙体持平悬停，自动生成闭合房间 |
| **W** | 矩形房间 | 拖拽或两点点击极速创建封闭矩形房间 |
| **E / V** | 选择工具 | 选中墙体、门窗、摆件家具或房间名称 |
| **A** | 单开门 | 点击墙体快速开洞放置 |
| **S** | 双开门 | 放置入户大门或双开门 |
| **D** | 推拉门 | 放置阳台、厨房推拉门 |
| **F** | 窗户 | 放置飘窗/普通窗，选中状态下按 F 快速翻转开向 |
| **Z** | 垭口 | 放置无门扇通行洞口 |
| **M** | 移动户型图 | 整体平移当前楼层所有户型元素 |
| **Space** | 居中复位 | 画布缩放并居中适配 |
| **Delete / Backspace** | 删除选中项 | 删除当前选中的墙体、门窗或摆件 |
| **Ctrl + Z / Y** | 撤销 / 重做 | 完整的操作历史记录 |

### 2. 摆件微调与贴墙快捷键
| 快捷键 | 功能 |
| :--- | :--- |
| **↑ ↓ ← → 方向键** | 沿屏幕方向精准微调当前选定摆件 **1 个像素点** |
| **Ctrl + 方向键** | 沿屏幕方向快速移动当前选定摆件 **10 个像素点** |
| **Shift + 方向键** | 摆件自动向该方向**最近的墙体贴墙摆放**（自动吸附对齐表面） |
| **点击摆件主体** | 仅保留拖拽移动功能，不会误旋转 |
| **拖拽边缘控点** | 8 个方向控点自由缩放摆件长宽尺寸 |
| **独立旋转按钮** | 摆件上方圆形旋转按钮：**单击顺时针转 90°**，**拖拽支持水平/垂直磁吸悬停** |

## 🏢 楼层管理与空状态绘制
- 画布左上角楼层控件支持 **向上添加 2F（+1）**、**向下添加 -1F（-1）**，严格遵循行业无 0 层规范。
- 支持将当前层户型图**一键完整复制至指定楼层**。
- 创建新空白楼层时，**不弹“尚未创建户型图”提示**，画布直接进入就绪状态并自动激活画墙工具，随点随画。
- 仅在点击顶部【新建户型】或首次打开空项目时才显示全屏引导卡片。
